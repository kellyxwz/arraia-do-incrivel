# 🎋 Arraiá do In-cri-vél

> Sistema de gestão digital para festas juninas focado em eliminar filas e otimizar o faturamento de barraqueiros e organizadores.

> Acesse o site para ver https://kellyxwz.github.io/arraia-do-incrivel/  

## 📌 Sobre o Projeto
Este projeto foi desenvolvido como parte da disciplina de Design para Web. O objetivo é oferecer uma solução tecnológica para eventos juninos em escolas, igrejas e empresas, substituindo as antigas fichas de papel por créditos digitais via Pix.

---

## 🚀 Funcionalidades e Jornadas
Conforme os requisitos do projeto, estruturamos três jornadas principais:

*   **Jornada do Visitante**: Compra de fichas digitais via QR Code e pagamento por Pix, eliminando a necessidade de filas físicas em caixas.
*   **Jornada do Barraqueiro**: Validação rápida de pedidos através da leitura do celular do cliente, garantindo higiene e agilidade.
*   **Jornada do Organizador**: Painel administrativo com métricas em tempo real para controle de estoque e faturamento por barraca.

## 🛠️ Tecnologias Utilizadas
*   **HTML5**: Estrutura semântica do site.
*   **Tailwind CSS**: Estilização moderna e responsiva baseada em Utility-First.
*   **JavaScript (ES6+)**: Lógica de interação, filtros de depoimentos e integração com API do WhatsApp.
*   **Google Fonts**: Fontes Bricolage Grotesque e Montserrat para identidade visual.

## 📱 Responsividade
O site foi projetado seguindo a filosofia **Mobile-First**, garantindo que a experiência seja fluida tanto em dispositivos móveis (foco principal do evento) quanto em desktops.
